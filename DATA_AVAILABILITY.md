# Data availability

This distribution contains original source code and deliberately invented examples only.
It contains no MIMIC-IV records or patient-level derivatives, institutional datasets,
real participant workbooks, clinical models, questionnaires, terminology corpora,
credential files, manuscript packages, or blinded benchmark/reviewer artifacts.

The owner confirmed ownership and MIT public-release authorization for these original
synthetic-only tools on 18 November 2026. That authorization does not cover underlying
clinical data or imply institutional endorsement. Dependencies retain their own licenses.

Synthetic markers are caller assertions, not a privacy or access-control system. Never
pass real protected records into these demonstrations or publish private inventory files
or runtime output. Use independently invented data for software experiments. Clinical
adaptation requires separate data access, provenance, ethics, scientific and deployment
review. No data download is performed by the published demonstrations.
