# Source provenance and scientific scope

SOURCE_PROVENANCE.json records each preserved source/test/fixture file, its original
project-relative location and SHA-256. The paths are labels, not data-source locators.
Original research files remain unchanged. Newly authored packaging/documentation is
identified separately by the positive RELEASE_MANIFEST.json of this distribution.

This repository starts with a clean initial history. It does not import private or
historical research Git objects. That bounds the release-history review to its approved
payload; it does not certify every original project history. Preserved functions may
carry earlier internal version identifiers and clinical HOLD flags. Those are retained:
publishing engineering code does not approve clinical phenotypes, model training or
patient use. No scientific originality, clinical utility or peer-review status is claimed.
